Deploy to Your GitHub Pages in 60 Seconds

This entire application is self-contained in a single index.html file and requires zero backend servers. Run these commands in your terminal where index.html is saved:

1. Push to GitHub Repository 
git init
git branch -M main
git add index.html
git commit -m "Deploy 2x2 phone screenshot grid to PDF app"
# If using GitHub CLI (creates repo & pushes automatically):
gh repo create screenshot-grid-pdf --public --source=. --remote=origin --push

2. Activate GitHub Pages

  1. Open your repository on GitHub and click Settings → Pages.
  2. Under Build and deployment → Branch, select main and / (root), then click Save.
  3. Your live app will be available at https://<your-username>.github.io/screenshot-grid-pdf/.
